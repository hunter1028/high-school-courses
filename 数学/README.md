# 高中数学系统化整理项目

定位：面向辽宁大连高中数学学习，教材体系为**人教B版（2019版）**，按教材章节建立可持续完善的复习与训练导航站。

## 页面形态

- **单页外壳**：`index.html` 是唯一入口，由紧凑标题栏、左侧教材树和右侧章节内容组成。导航与内容同屏；左侧菜单默认宽 304px，可拖动右边界调整宽度。
- **顶部面包屑**：固定显示“人教B版 高中数学 › 根目录 › 章号 + 当前章节名”。章节子页内不重复显示该标题或教材册信息。
- **导航树层级**：根目录为“必修”“选择性必修”和底部独立的“总结与补充”；前两个根目录下直接列“章号 + 章节名”，不设置“第几册”层级。已完成章节可继续展开本章子内容。
- **树的缩进**：根目录、章节、本章栏目必须以逐级加深的缩进和连接线区分，不能把三级内容压成同一左边界。
- 子节点锚点链接用 `target="viewer"` 指向章节页 `#section-id`，只在 iframe 内做片段定位，不整页刷新。
- 未完成章节仅灰显，不添加“待完善”、进度、数量统计等说明文字；完成后替换成可点击章节节点并挂子节点。
- 每个章节一个 `chapters/<slug>.html` 子页，body `class="chapter-page"`，正文包在 `<div class="chapter-doc">`；不做独立顶栏/侧栏（导航由外壳承担）。
- **菜单控制**：折叠/展开只用菜单顶部的箭头图标表示；折叠后保留窄侧栏与展开图标，不能把控制入口藏到顶部标题栏或完全藏掉。

### 界面约束

1. 只显示帮助定位、阅读或操作的信息；删除册数、章数、完成状态、版本口号等无操作价值的尾注。
2. 同一信息只出现一次：章号和当前章节名放在外壳顶部，正文不再重复；导航保留章号，但不在节点文字中重复“必修 / 选择性必修”等上级名称。
3. 标题和菜单文字保持单一职责，不把教材版本、站点名称、当前位置拼成一串重复标题。
4. 外壳不得超出视口：页面固定为 `100vh`，导航和正文各自滚动；横向区域使用 `min-width:0`，长标题以省略号收束。
5. 窄屏下导航移到正文上方并限制高度；正文表格、公式和 SVG 只允许在自身区域横向滚动，不撑宽整个页面。
6. 新增界面文字前先检查：是否与标题、导航或正文重复，删除后是否影响用户判断下一步；不影响就不添加。
7. 字体使用系统中文无衬线字体，不为页面额外加载字体。正文统一为 16px 与约 1.72 行距；表格、题干和解析不得另降成难读的小字；菜单根节点 13px、子节点 12.5px，保证紧凑但不吃力。
8. 页面以文档层级区分内容，不用“每一块一个圆角边框”。章节只用细分隔线；题目、公式、解析和变式优先用留白、浅底色或单侧色线区分。只有真正需要交互或对照的内容才用完整边框。
9. “章节速览”只保留本章特点、与前置模块的关系及高考常见位置；不重复“建系 → 写坐标 → 写向量”等已在方法模板出现的流程口号，也不写无明确用途的补题数量建议。

### 交付职责与验收

1. 本项目交付的是能直接阅读和使用的 HTML 数学笔记，不是原始资料、纯文字大纲或只追求功能可运行的页面。每项内容都应同时检查知识表达、版面层级和实际阅读体验。
2. 完成页面修改前，必须检查桌面宽屏和窄屏：菜单可独立收起；正文使用可用宽度而不留下大块无意义留白；窄屏时导航、图文组和双栏内容自动改为纵向。
3. 公式、表格、SVG 和长标题不得撑破卡片、网格或视口。优先让正文换行；不能合理换行的公式与图表只在自身区域横向滚动，不能带动整页横向滚动。
4. 图和说明属于同一个知识单元时，宽屏优先采用“左图右说明”；窄屏改为先图后说明。图必须服务于文字，不为装饰单独占一整行。
5. 每次新增或修改 HTML 后，同步核对 README 约束；若新增了可复用的排版或交互规则，先写入 README 再作为后续章节的标准。
6. 公式字号不小于正文；短公式优先紧随知识点横向排布，长公式使用单侧色线的公式区。不得把“标题在上、公式在下”的小卡片机械铺满一行而留下大块空白。
7. 基础练习按知识块分组，但分组只用轻量小标题与留白，不能再套一层卡片。模拟练习和高考真题不放“模拟1 / 配图 / 题型”等无操作价值标签。
8. 五、基础练习，六、模拟练习，七、高考真题默认折叠；真题的变式放在同题“精讲”内，不独立悬在题目外。

## 通用章节 HTML 模板（后续章节必须遵守）

### 1. 导航与定位

1. 顶部只使用面包屑：`人教B版 高中数学 › 必修/选择性必修/总结与补充 › 第X章 章节名`。不再另设居中大标题或重复站点名。
2. 左侧树固定为“根目录 → 章节 → 本章栏目”三级，三层必须有明显递进缩进、连接线与字号/字重差异。
3. 默认折叠与当前章节无关的根目录；默认展开当前根目录和当前章节。菜单可由图标折叠成窄栏，默认宽约 304px，并可拖拽调整。

### 2. 正文信息架构

1. 每章固定保留：章节速览、知识清单、方法模板、易错、基础练习、模拟练习、高考真题、薄弱环节。
2. 章节速览用一段完整说明交代：前置模块/关联模块、该章解决什么问题、在高考中常出现的位置与核心考法。不要重复后文已有的机械流程。
3. 知识清单不能只堆公式；至少写清概念定义、适用条件、基本定理、表示方式、公式的取值范围或符号约定、常见推论与反例边界。
4. 知识清单按概念依赖排序：一个术语必须先定义，再用于后续公式。例如法向量必须放在线面角、面面角和点面距之前；不能为了版面整齐而把前置概念放到最后。
5. 角、距离、向量等内容必须分清对象。角按“对象 → 公式 → 精确取值范围”书写，不用“通常取锐角”等模糊表述；必须区分 $(0,\frac\pi2]$ 与 $[0,\frac\pi2]$，并区分两平面的较小夹角与二面角。公式已经显示绝对值时，不再增设重复的“加/不加绝对值”说明列。
6. 定理若表达充要条件，必须用 $\Longleftrightarrow$ 写出双向关系；结论包含唯一性时用 $\exists!$ 或文字明确“唯一”。
7. 抽象算法不能只写“令某个未知数为 1 或 2”等口令；至少配一个“设 → 列 → 取/解 → 验”的完整小例题，再从例题中提炼方法。
8. “易错”使用单列短条目：错误点 + 正确规则。删除泛泛的补题数量、口号和无行动价值的建议。
9. 同一组递进概念使用一致记号。例如一维、二维、三维统一采用 $\mathbf e_1,\mathbf e_2,\mathbf e_3$ 表示基向量，只通过基向量数量体现维数变化；不得无说明地换成另一套字母。

### 3. 正文版式

1. 正文必须体现三级阅读层次：章标题不缩进；小节标题内缩；小节下的说明、公式、表格和图文再内缩。用缩进、留白、字号和字重提示归属；不能为了表现缩进而增加装饰性竖线，也不能叠加卡片。
2. 默认正文 16px、行高约 1.72；公式不小于正文，表格、题干和解析不得缩成难读的小字。
3. 页面采用扁平讲义式排版：章节和题目用细分隔线；公式、解析、变式优先用单侧色线或浅底色；避免“每块一个圆角边框”。
4. 图文属于同一知识点时必须紧邻，不能让图与说明分散。方法说明可用左图右文；连续的概念、角或距离参考项优先左侧定义/公式、右侧对应图。窄屏统一改为单列；题目之间保留明显但克制的分隔。
5. 共面、投影、垂距、角度等仅凭公式不直观的空间关系必须配 SVG 示意图。公式中用于解释图形的符号必须在图中出现，例如任意点 $A$ 与垂足 $H$ 不能遗漏或混同；直角符号的两端必须落在所表示的两条垂直射线上。点在线上、垂足位置、平行和垂直关系必须由坐标或向量验算，不能只凭外观看似正确。用一句图注解释图与公式的对应关系。
6. 自制 SVG 的样式使用直接子元素选择器（如 `.diagram > svg`），避免影响 MathJax 在公式中生成的嵌套 SVG，造成公式逐字或逐项断行。
7. 连续介绍角或距离时采用“一概念一行”：宽屏左侧放定义、公式和紧邻的区间，右侧放唯一对应的图；窄屏改为文字在上、图在下。图应表现投影、正交分解、法向量或公垂线为什么导出公式，而不是只画最终对象。

### 4. 练习与打印

1. 基础练习按知识块分组，分组只用小标题与留白；五、六、七默认折叠。
2. 模拟题不加无作用标签。高考题的变式写入该题精讲内部。
3. 每个练习区仅在标题栏右侧设置一个“打印”按钮。点击后勾选题目，再进入预览。
4. 打印稿只保留题干、必要图形和作答区；普通题留基本作答区，综合/配图/高考题留更大作答区。

### 5. 完成前检查

- 面包屑、当前根目录和当前章节是否一致。
- 正文是否存在重复标题、重复流程、无用标签、无用统计或泛泛口号。
- 每个公式是否没有超出容器，并写明必要条件、角度范围或绝对值规则。
- 桌面宽屏、窄屏、菜单收起、五六七折叠、选择题目打印是否都能正常使用。
- 本章 HTML 是否通过结构检查；Markdown 除非用户明确要求，不同步修改。
- 是否实际打开并检查了浏览器渲染截图；没有查看桌面与窄屏的真实结果，不得仅凭源码声称“已检查”“无溢出”或“已经修好”。

### 打印功能约定（页内选择与预览）
- 每个练习分区标题栏最右侧只放一个“打印”按钮；不在每道题旁重复放打印按钮。点击后再勾选题目。基础练习、模拟练习和高考真题遵循同一规则。
- 点击后先在打印浮层勾选题目，再预览。预览只保留题干、必要配图和作答区；去掉按钮、答案 `<details>`、标签、变式和解析。
- 每题预留带横线的作答区；含配图、综合题或高考题使用更大的作答区。浮层标题栏提供 **打印** 与 **关闭预览** 两个按钮；点“打印”只输出该预览。
- 打印预览由 CSS 完成：`body.pv-open` 时 `@media print` 只显示 `.pv-backdrop`，无需 JS 还原。
- 新章节沿用 `data-print="section"` + `data-target` 即可，交互脚本和浮层直接复制章节页内 `<div class="pv-backdrop">` + 底部 `<script>`。

### 薄弱环节（`#weakness`）维护规则
- 页面默认空（`<ul id="weaklist">`）。
- **后续对话中一旦暴露学生的知识疑点/薄弱点**，就把具体条目追加到该 `ul`（HTML 与 README 同步更新；Markdown 仅在用户明确要求时更新），条目形如：`<li><b>知识点：</b>具体表现 → 补法</li>`；只保留“该生真正薄弱”的点，不堆通用提醒。
- 该列表是学生档案的一部分，跨章节保留；换章节时把相关条目复制/移入对应章节页。

## 内容与书写规范
1. 内容直接给学生使用，不用教师口吻；可写“自查 / 书写提醒 / 易错提醒 / 规范作答 / 解析”。
2. 排版紧凑（类 Markdown）：去掉冗余、重复、啰嗦表达；流程用“→”；题组标题直接带时限，如“五、基础练习（25分钟）”，不另写“先做后看答案”类废话；不写“按高考卷面写：……”、不加“卷面注意”式提示条（标准步骤本身即示范）。
3. 能画图的题尽量配 SVG 示意图。**图不放外框、不居中、靠左**，像试卷排版：`<figure class="diagram">` 无边框无底色。HTML 少嵌套（题目不用多余 div 包裹，标签 `.pill` 与题干同一行）。
4. 每题讲解顺序：**解析：**（思路指引，先写）→ **证明：/解：**（标准卷面步骤）→ 变式。
5. 高考真题固定链条 **年份—卷别—题号—原题—精讲—变式**：出处压缩成一行，如 `2022·新高考Ⅰ卷·第9题（多选）`；非原卷逐字题必须带“同考点改编/同考点转写”小标。
6. **行文逻辑词**：用汉字“因为……所以……、故……”，把条件写全即可；**不用“∵/∴”符号**，也不为凑格式加省略号。
7. **向量记号（教材惯例，必须遵守）**：
   - 单个向量字母用粗体：$\mathbf a,\mathbf u,\mathbf v,\mathbf n$；
   - 两点确定的向量用箭头：$\overrightarrow{AB},\overrightarrow{AP}$，禁止写成 $\mathbf{AB}$；
   - 线段、长度、坐标等按教材常规书写；不要任何“记号说明”废话。
