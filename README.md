## 当前内容

数学目录已收录人教 B 版高中数学 HTML 笔记站点，入口为 [`数学/index.html`](./数学/index.html)。目前包含“空间向量与立体几何”章节，页面可直接在浏览器打开，无需安装依赖或启动服务器。

## 目录约定

```text
high-school-courses/
├── 语文/
├── 数学/
│   ├── index.html
│   ├── assets/
│   └── chapters/
├── 英语/
├── 物理/
├── 化学/
└── 生物/
```

- 每个学科拥有独立根目录，学科内部自行组织章节、专题、练习和资源。
- 可直接阅读的 HTML 是主要交付形式；样式与章节资源放在相应学科目录内，避免跨学科路径依赖。
- 新增资料时保留教材版本、章节名称和来源信息；不上传临时截图、缓存或系统文件。
